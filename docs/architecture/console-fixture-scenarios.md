# Console Fixture Scenarios

The scenario list the browser tier drives, for the tests [Plan-020: Desktop App And Renderer](../plans/020-desktop-app-and-renderer.md) builds.

Each scenario is a screen state to reach and what must be true once it is reached. They are the fixture scenarios the app starts on with `--fixture <scenario>` (and `--session <session-id>` where a scenario holds several sessions), so the tier drives them with no daemon and no provider process.

**The session screen.** Ten fixture sessions carry its states, and a scenario names the one it is reached on: **the live project session** (a Claude Code project session mid-turn), **the settled project session**, **the Codex project session**, **the committed project session** (on a mid-tier Claude model), **the file-writing chat**, **the chat that wrote nothing**, **the Codex question session**, **the plan-mode session**, **the three-question session**, and **the archived session**.
